## Breaking

- **MD041** is now enabled. Every Markdown file must begin with a top-level `#`
  H1, or satisfy the default frontmatter `title:` regex
  (`^\s*title\s*[:=]`). Files with neither (embeddable fragments, some PR
  templates, content keyed on other frontmatter fields) will fail until
  consumers add a `title:`, an H1, an `ignores` entry, or an inline
  `<!-- markdownlint-disable-next-line MD041 -->`.

## Changed

- Flipped `MD041` to `true` in `.markdownlint.jsonc` with updated rationale
  ([R-1199](https://linear.app/rheged-studio/issue/R-1199), split from [R-929](https://linear.app/rheged-studio/issue/R-929) after the estate audit).
- Synced `README.md` philosophy, rule inventory, and customisation example with
  MD040/MD041 and the [R-929](https://linear.app/rheged-studio/issue/R-929) style-locks.
